# Monogram (production)

Standalone stylized **W** (serif + sweeping wing/movement stroke). No wordmark.

## Files

| File | Format | Color | Use |
|------|--------|-------|-----|
| `wren-wold-monogram.svg` | SVG (vector paths) | `#242321` | Primary monogram on light backgrounds |
| `wren-wold-monogram.png` | PNG (transparent) | `#242321` | Raster / print / embroidery masters |
| `wren-wold-monogram-white.svg` | SVG (vector paths) | `#F3F2EF` | Reversed monogram on dark backgrounds |
| `wren-wold-monogram-white.png` | PNG (transparent) | `#F3F2EF` | Raster reversed |

## Primary usage

- Favicon / app icon source
- Social avatar
- Garment label, packaging stamp / embossing
- Compact UI branding where the wordmark would fail

## Reversed usage

Use `*-white.*` on dark charcoal, moss, stone, or dark photography.

## Minimum recommended sizes

- Monogram height ≥ **24px** (reference sheet)
- Prefer SVG above ~48px; use favicon-optimized PNGs for 16–48px UI chrome

## Formats

- **SVG** — preferred scalable mark (true vector paths)
- **PNG** — transparent background
