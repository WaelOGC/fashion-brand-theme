# Favicon / app icons (production)

Monogram-only. No wordmark.

## Files

| File | Size | Use |
|------|------|-----|
| `wren-wold-favicon.ico` | 16 / 32 / 48 (multi-size) | Classic browser favicon |
| `wren-wold-favicon-16.png` | 16×16 | Tiny tab / bookmark |
| `wren-wold-favicon-32.png` | 32×32 | Standard favicon PNG |
| `wren-wold-favicon-48.png` | 48×48 | Higher-density favicon |
| `wren-wold-favicon-180.png` | 180×180 | Apple touch icon |
| `wren-wold-favicon-192.png` | 192×192 | Android / PWA |
| `wren-wold-favicon-512.png` | 512×512 | PWA / high-res app icon |

## Color

Dark monogram `#242321` on transparent background (except where the host platform requires a solid tile).

## Notes

- Optimized for silhouette at 16px and 32px
- Do not substitute the full horizontal logo for favicons
- For solid circular social avatars, place the monogram on approved palette fields (see `docs/LOGO_GUIDELINES.md`)
