# Logo (production)

Horizontal lockup: **W monogram + WREN WOLD wordmark**.

## Files

| File | Format | Color | Use |
|------|--------|-------|-----|
| `wren-wold-logo-primary.svg` | SVG (vector paths) | `#242321` | Primary lockup on light backgrounds |
| `wren-wold-logo-primary.png` | PNG (transparent) | `#242321` | Raster fallback / CMS uploads |
| `wren-wold-logo-white.svg` | SVG (vector paths) | `#F3F2EF` | Reversed lockup on dark / photographic backgrounds |
| `wren-wold-logo-white.png` | PNG (transparent) | `#F3F2EF` | Raster reversed fallback |

## Primary usage

- Website header (when width allows)
- Packaging and print where the full name should read with the mark
- Primary brand applications

## Reversed usage

Use `*-white.*` on charcoal, moss, stone, or dark photography. Do not recolor outside `#242321` / `#F3F2EF`.

## Minimum recommended sizes

- Prefer monogram-only below ~160px lockup width
- Wordmark should stay readable; do not shrink the lockup under ~120px wordmark width
- Maintain clear space ≈ monogram stroke height around the mark

## Formats

- **SVG** — preferred for web UI (true vector paths; no embedded raster)
- **PNG** — transparent background for contexts that require raster
