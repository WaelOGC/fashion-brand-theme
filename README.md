# WREN WOLD Fashion Brand WordPress Theme

Custom WordPress + WooCommerce theme for a European fashion brand (pre-launch).

## What's in this repo

- `app/public/wp-content/themes/fashion-brand-theme/` — custom theme
- `docs/` — project architecture, design system, and development rules

## Requirements

- WordPress 6.x
- PHP 8.2+
- WooCommerce (when e-commerce features are enabled)

## Local development

1. Create a WordPress site in [Local](https://localwp.com/).
2. Clone this repository into your Local site folder, or copy the theme into `wp-content/themes/`.
3. Install and activate WooCommerce if needed.
4. Activate the **Fashion Brand Theme** in WordPress admin.

## Documentation

See the `docs/` folder for project overview, technical architecture, design system, and development rules.
